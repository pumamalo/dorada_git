# Sistema de medida automatizado de la cámara de aire en huevos de gallina autóctona Murcia

| Proyecto | Sistema de medida automatizado de la cámara de aire en huevos de gallina autóctona Murcia | 
| --------- | --------- | 
| Autor | PJNL | 
| Ubicación | Este proyecto está siendo desarrollado en el laboratorio de _Visión Artificial y Vehículos Inteligentes_ de la Universidad Politécnica de Cartagena (UPCT) | 
| Descripción | El proyecto está desarrollado un sistema de medida autoamtizado de la cámara de aire en huevos de gallina autóctona Murcia. El proyecto se realiza en colaboaración con profesores del departamento del producción animal de la UPCT.|
